# 📈 OFZ Daily Assistant

Автоматический торговый бот для покупки ОФЗ (облигаций федерального займа) через Т-Инвестиции (Тинькофф) для двух портфелей.

## 🛠 Как это работает (пошагово)

1. **Запуск и инициализация.**
   Скрипт запускается (по расписанию или вручную). Он проверяет наличие переменных окружения `TINKOFF_TOKEN` (для первого портфеля) и `TINKOFF_TOKEN_2` (для второго). Если хотя бы один токен найден, начинается работа.

2. **Разделение на портфели.**
   Логика вынесена в функцию `process_account`, которая вызывается отдельно для каждого токена. Это позволяет обрабатывать оба портфеля независимо друг от друга в рамках одного запуска.

3. **Аудит (полный вывод состава).**
   Для каждого портфеля скрипт делает следующее:
   - Получает номер счёта (`account_id`).
   - Запрашивает свободный остаток в рублях (`get_free_rub`).
   - Вызывает `client.operations.get_portfolio()` для получения всех позиций.
   - Проходит циклом по каждой позиции и определяет её тип (`instrument_type`).
   - В зависимости от типа (`bond`, `share`, `etf`, `currency`) запрашивает детали через соответствующие методы (`bond_by`, `share_by` и т.д.) и выводит в лог:
     - **Для облигаций:** `[Класс] Тип Тикер (Название): Количество шт, цена=X₽, НКД=Y₽`
     - **Для акций:** `[Акция] Тикер (Название): Количество шт, цена=X₽`
     - **Для фондов:** `[Фонд] Тикер (Название): Количество шт, цена=X₽`
     - **Для валюты:** `[Валюта] FIGI: Количество, цена=X₽`

4. **Фильтрация для торговли.**
   После вывода полного состава портфеля, скрипт формирует список только тех бумаг, которые подходят для торговли:
   - Функция `get_bonds_in_portfolio` отбирает только облигации с `class_code == "TQOB"` (ОФЗ).
   - Рассчитывается полная стоимость лота (`lot_price_rub = price_rub + nkd`).
   - Выводится список найденных ОФЗ с их параметрами.

5. **Проверка порога.**
   Если свободных рублей меньше `MIN_THRESHOLD_RUB` (600 рублей), работа с этим портфелем завершается с сообщением об ошибке.

6. **Торговая логика (только для ОФЗ).**
   Если порог пройден, скрипт вызывает `select_bond_to_buy`, которая:
   - Отсеивает ОФЗ, где НКД больше 50% от размера купона.
   - Сортирует оставшиеся по возрастанию НКД.
   - Возвращает первую (с минимальным НКД).
   Затем `calculate_buy_quantity` считает, сколько лотов можно купить на свободные деньги, и если количество больше нуля, выставляется рыночная заявка на покупку через `client.orders.post_order`.

7. **Результат.**
   В логе отображаются все действия по каждому портфелю: что найдено, что отфильтровано, что выбрано и была ли совершена покупка (или почему она не совершена).

## 🚀 Как это запускается

- **Внешний cron-job.org:** Пингует GitHub API каждый день в 22:00 МСК (основной триггер).
- **Встроенный GitHub Actions:** Резервный запуск `cron: '0 19 * * *'` (19:00 UTC).

## ⚙️ Настройка

- Секреты `TINKOFF_TOKEN` и `TINKOFF_TOKEN_2` должны быть добавлены в настройках репозитория (Settings -> Secrets -> Actions).
- Настройки в `main.py`:
  - `MIN_THRESHOLD_RUB = 600.0` — порог для запуска.
  - `COUPON_NKD_LIMIT_RATIO = 0.5` — лимит переплаты по НКД.

## 💻 Запуск локально

1. `python3 -m venv venv`
2. `source venv/bin/activate`
3. `pip install https://github.com/Invest-SDK/invest-python/raw/refs/heads/master/t_tech_investments-1.51.0-py3-none-any.whl`
4. `export TINKOFF_TOKEN=ваш_токен`
5. `python3 main.py`
