# 📈 OFZ Daily Assistant

Автоматический торговый бот для покупки ОФЗ (облигаций федерального займа) через Т-Инвестиции (Тинькофф).

## 🛠 Как это работает

1. **Проверка порога:** Если на счете меньше 600 рублей, бот завершает работу.
2. **Сбор портфеля:** Бот находит все облигации в портфеле.
3. **Проверка НКД:** Бот не покупает облигацию, если НКД больше 50% от размера купона (чтобы не переплачивать).
4. **Выбор цели:** Из подходящих облигаций выбирается та, у которой самый маленький НКД.
5. **Расчет количества:** Бот покупает максимальное количество лотов на все свободные деньги.
6. **Покупка:** Отправляется рыночная заявка (Market Order).

## 🚀 Как это запускается

- **Внешний cron-job.org:** Пингует GitHub API каждый день в 22:00 МСК (основной триггер).
- **Встроенный GitHub Actions:** Резервный запуск `cron: '0 19 * * *'` (19:00 UTC).

## ⚙️ Настройка

- Секрет `TINKOFF_TOKEN` должен быть добавлен в настройках репозитория (Settings -> Secrets -> Actions).
- Настройки в `main.py`:
  - `MIN_THRESHOLD_RUB = 600.0` — порог для запуска.
  - `COUPON_NKD_LIMIT_RATIO = 0.5` — лимит переплаты по НКД.

## 💻 Запуск локально

1. `python3 -m venv venv`
2. `source venv/bin/activate`
3. `pip install https://github.com/Invest-SDK/invest-python/raw/refs/heads/master/t_tech_investments-1.51.0-py3-none-any.whl`
4. `export TINKOFF_TOKEN=ваш_токен`
5. `python3 main.py`
